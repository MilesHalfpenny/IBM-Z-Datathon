# IBM-Z-Datathon
Project: Creating an application where AI is used to retrieve and display recipes depending on the user's dietary requirements/limitations.

Team: Offloading
Members: Miles, Sara, Zhi, Henry, Rhys, Azhar

### Overview
The problem we are attempting to solve is to accommodate users with dietary restrictions or preferences by providing them with suitable recipes from the database. 
Our application will utilize AI to analyze user input regarding their dietary needs and generate a list of recipes that align with those requirements.
